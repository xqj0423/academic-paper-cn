# 工程计算与文献核验指南 (Verification Protocol)

> **性质说明**：本文件为供 AI Agent 执行的**核验工作流规范与结构化检查清单 (Review Protocol & Checklist)**，用于指导工科论文在规划、撰写与复核过程中的力学自洽性与数据合规性审查。
> **注意**：本文件**并非**自动化计算验证器程序，各项具体的数值复核、力学推导与公式计算仍需依托独立编写的计算脚本或由作者人工核验。

工科论文与算法工具类文章的核心生命线在于**数据的真实性、力学计算的自洽性与文献来源的可靠性**。本指南规定了 `academic-paper-cn` 建议执行的内容核验标准。

---

## 1. 双轨计算复核体系 (Dual-Track Verification)

针对传统文本审校无法识别“程序算错、逻辑自洽但力学失真”的盲区，建立两套独立计算链路：

```
[ 源码模块计算输出 (bolt_calc) ]       [ 理论公式独立推导 (Step-by-step Script) ]
             \                                      /
              \                                    /
               +---> [ 双轨数值一致性比对 (Diff = 0) ] <---+
```

### 1.1 双轨复核强制要求
1. **禁止直接抄写**：严禁直接从代码中复制输出值贴入论文当作手算验证值；手算过程必须基于论文公开呈现的理论公式编号（如式 (1)～(18)）独立推演。
2. **完整保留中间物理量**：在算例对比表中，除最终判定（通过/不通过）外，必须完整罗列并比对所有关键中间量：
   - 螺纹小径计算截面积 $A_1$；
   - 螺栓群组极惯性矩 $\sum r_i^2$、倾覆几何惯性矩 $\sum l_i^2$；
   - 工作当量载荷 $F_w$、残余预紧力 $F_1$；
   - 矩形接合面抗弯截面模量 $W$。
3. **精度与有效数字要求**：
   - 应力值建议保留 2 位小数（如 $388.96\text{ MPa}$），避免过早四舍五入掩盖算术偏差；
   - 裕度百分比应精确给出，便于评审专家直观评估安全余量。

## 2. 量纲与法定计量单位一致性审查 (Dimensional Consistency)

工程计算中 70% 以上的重大错误来源于“量纲混淆”（尤其是米制与毫米制、力矩与力的混用）。

### 2.1 标准单位对照表
| 物理量类别 | 规范符号 | 论文推荐单位 | 换算与量纲防错重点 |
| :--- | :--- | :--- | :--- |
| **力 / 载荷** | $F, F_0, F_Q, F_z$ | $\text{N}$ | 若题目给出 $\text{kN}$，必须先乘以 $10^3$ 转换为 $\text{N}$ |
| **几何尺寸 / 直径 / 厚度** | $d, d_1, d_0, l_i, \delta$ | $\text{mm}$ | 严禁在截面模量或面积公式中使用米（$\text{m}$） |
| **截面积** | $A_1, A_0, A$ | $\text{mm}^2$ | $A = \pi d^2 / 4$ |
| **力矩 / 扭矩** | $T, M$ | $\text{N}\cdot\text{mm}$ | **重点排查**：工程中常习惯写为 $\text{N}\cdot\text{m}$，代入应力公式前必须乘以 $10^3$（$1\text{ N}\cdot\text{m} = 10^3\text{ N}\cdot\text{mm}$） |
| **抗弯截面模量** | $W$ | $\text{mm}^3$ | 矩形接合面 $W = b h^2 / 6$ |
| **应力 / 压强** | $\sigma, \tau, \sigma_p, [\sigma]$ | $\text{MPa}$ | $1\text{ MPa} = 1\text{ N/mm}^2$，与上述量纲天然闭环 |

## 3. 边界条件与保守界对抗测试 (Boundary & Envelope Testing)

论文中提出的新理论模型或折算方法，必须经受经典极限工程条件的对抗检验：

### 3.1 标量叠加 vs 矢量合成对抗分析
- **物理现象**：横向均摊剪力与转矩切向分量在空间不同螺栓上的受力方向各不相同。
- **检验标准**：必须进行逐螺栓平面矢量合成（如式 (13)）；同时与简单的标量极大值绝对相加进行量化对比，指出标量叠加造成的过度保守与材料浪费（如高估 5% 剪力）。

### 3.2 统一刚度模型 vs 经典保守界（$\chi = 0$）对照
- **接合面抗分离边界**：
  - 当采用考虑螺栓附加拉力分担力矩的统一下载模型（$\chi > 0$）时，接合面边缘最小压应力计算值偏高；
  - 必须同时引入 $\chi = 0$ 的经典极限作为保守界，并在论文中清晰呈现：若某一工况在现有模型下判定不分离，但在 $\chi = 0$ 保守界下出现微张分离（$\sigma_{p,\min} < 0$），必须客观提示分离风险，严禁隐瞒对抗测试结果。

## 4. 未核验数据与文献披露标准 (Unverified Data Tagging)

AI 辅助论文必须杜绝“学术幻觉”。对于无法 100% 确认原始文献的数据，统一采用规范化标签：

### 4.1 五类强制标注标签
1. **`【设计输入】`**：属于工程算例自行假定的参数（如安全系数 $S=1.5$、摩擦系数 $f=0.15$），非国家标准强制规定。
2. **`【示例输入】`**：用于验证计算链路完整性的临时输入（如底板有效厚度 $\delta_{\min}=15\text{ mm}$）。
3. **`【未核对原书】`**：引用的教材或参考书目缺少出版年、版次、出版社版权页原始扫描件验证（如文献 [5] 高文英《机械设计基础》）。
4. **`【未核对现行版原文】`**：数据来源于旧版标准或教材引用，尚未与现行替代标准官方文本比对（如 GB/T 196—2003 与 GB/T 196—2025 的外螺纹小径代号 $d_1 \to d_3$）。
5. **`【作者填写 / 待补全】`**：需要作者本人根据实际实验数据、机构身份填写的预留字段。

---

## 5. 公式与引文映射闭环审查 (Formula & Citation Audit)

1. **公式编号与正文引用一致性**：检查正文中的“式 (N)”引用与对应的数学公式标号 `\tag{N}` 是否严格一致，严禁出现编号漂移。
2. **符号表覆盖度**：正文理论公式中出现的所有希腊字母、下标变量必须全部在“符号表”中有明确定义与量纲。
3. **引文角标语法防暴雷**：
   - 严禁书写相邻美元符号的角标语法（如 `$0.2 \sim 0.3$$^{[1]}$`）；
   - 正式 Markdown 中统一采用 `<sup>[1]</sup>` 标签，保障任意渲染器解析安全。
